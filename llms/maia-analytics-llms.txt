# MAIA Analytics

> MAIA is an AI-powered geospatial analysis platform that lets anyone turn complex location data into actionable insights through natural-language queries — no GIS degree required. Use cases include solar-site prospecting, building/parcel analysis, redevelopment and risk (flood/aging-infrastructure) screening, and location intelligence. Founded 2023; backed by Homebrew.

This llms.txt was generated by the API Evangelist enrichment pipeline from the company's public site and its publicly-served backend OpenAPI. MAIA does not publish an external developer program; the API below is the application's own backend (Firebase ID-token bearer auth).

## APIs
- [MAIA API (OpenAPI 3.1)](https://api.maia-analytics.com/openapi.json): 174-path FastAPI backend covering projects, layers, map tiles, tables, chat, enrichment, saved contacts, dialing, sharing, and workspaces.
